# Тестовые матрицы для `task_6`

Файл содержит `n²` чисел в порядке строк. Размер `n` задаётся в командной строке, `m` ограничивает объём печати, `eps` задаёт абсолютную точность, `k=0` включает чтение из файла.

Сборка и запуск из корня репозитория

```bash
make -C task_6
python3 task_6/test.py
```

Один запуск с файлом масштаба `10^-20`

```bash
./task_6/a.out 4 4 1e-31 0 test_data/task_6/dense_em20_4.txt
```

Скрипт сравнивает количество и значения собственных чисел в порядке возрастания с эталоном, учитывает точность печати и проверяет обе невязки. Для масштабированных матриц он выбирает `eps = 1e-11 * |c|`, где `c` — множитель, и сравнивает спектр после деления на `|c|`. Для некорректного ввода ожидаются ненулевой код выхода и сообщение об ошибке. Завершение по сигналу или тайм-аут считаются провалом проверки.

## Некорректные входные данные

Все файловые проверки в этой группе запускаются с `n=2`.

| Файл | Проверка |
| --- | --- |
| `empty_2.txt`, `whitespace_2.txt` | Пустой файл и файл с одной пустой строкой |
| `short_2.txt` | Три числа вместо четырёх |
| `extra_number_2.txt`, `extra_text_2.txt` | Лишнее число или текст после матрицы |
| `text_2.txt`, `comma_2.txt` | Текст вместо числа или запятые между числами |
| `broken_exponent_2.txt` | Незаконченная экспоненциальная запись `4e+` |
| `nan_2.txt`, `inf_2.txt`, `overflow_2.txt` | `nan`, `inf` и число `1e309` вне конечного диапазона `double` |
| `broken_2.bin` | Повреждённый файл с байтами `00` и `FF` перед последним числом |
| `non_symmetric_2.txt` | Четыре корректных числа образуют несимметричную матрицу |
| `missing_2.txt` | Путь к отсутствующему файлу |

Скрипт также проверяет некорректные значения `n`, `m`, `eps` и `k`, в том числе `n=2x`, и случаи неправильного использования аргумента `filename`. При провале проверки скрипт печатает команду запуска и завершает весь прогон с кодом `1`.
