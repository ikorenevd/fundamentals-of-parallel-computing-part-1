# Матрицы для тестов

Размер задаётся аргументом `n`, в самих TXT-файлах заголовков нет.

| Файл | n | Назначение |
| --- | --- | --- |
| `scalar_1.txt` | 1 | Минимальный размер |
| `identity_3.txt` | 3 | Единичная матрица |
| `dense_4.txt` | 4 | Несимметричная матрица; проверка порядка элементов |
| `mixed_3.txt` | 3 | Знаки, дробные числа, экспоненциальная запись |
| `singular_3.txt` | 3 | Вырожденная матрица с корректным форматом |
| `zero_3.txt` | 3 | Нулевая матрица с корректным форматом |
| `matrix with spaces_2.txt` | 2 | Пробелы в имени файла |
| `invalid_empty.txt` | 2 | Пустой файл |
| `invalid_short_3.txt` | 3 | Недостаточно чисел |
| `invalid_extra_2.txt` | 2 | Лишнее число |
| `invalid_text_2.txt` | 2 | Текст вместо числа |
| `invalid_suffix_2.txt` | 2 | Буквы после числа |
| `invalid_separator_2.txt` | 2 | Допустимая запись `2-2 2 1`: матрица `[[2, -2], [2, 1]]` |
| `invalid_nan_2.txt` | 2 | NaN |
| `invalid_inf_2.txt` | 2 | Допустимое значение inf (старое имя файла) |
| `invalid_overflow_2.txt` | 2 | Переполнение при чтении даёт inf; проверяется ввод и вывод |
| `invalid_rhs_overflow_3.txt` | 3 | Числа допустимы, но сумма для b переполняется |

Запуск из корня проекта:

```bash
bash task_2/test.sh
```

Скрипт работает из любого каталога при указании пути к нему. Нужны
C++11-компилятор, GNU Make, Bash и Python 3 (только стандартная библиотека).
Bash собирает программу и `build/test_numerics`, затем запускает
`tests/test_cli.py`. Уже собранные исполняемые файлы можно проверить отдельно:

```bash
python3 task_2/tests/test_cli.py
```

Проверки CLI выполняются снаружи: Python запускает `a.out`, передаёт
аргументы и файлы, проверяет stdout, stderr и код возврата. Дополнительно
`tests/test_numerics.cpp` проверяет норму и код возврата решателя через
открытые функции, а Python сверяет вывод общей функции печати прямоугольных
матриц. Доступ к закрытым полям и перехват аллокаторов не используются.
Генерируемые матрицы хранятся во временном каталоге и автоматически удаляются.
Любой провал проверки даёт ненулевой код возврата скрипта.

Проверяются:

- Четыре формулы генерации матрицы, вывод матрицы, правой части и решения.
- Чтение перечисленных файлов, ошибки ввода и аргументов командной строки.
- Ограничение вывода при r=0, r<n, r=n и r>n.
- Несимметричные матрицы и матрицы с нулевой правой частью при n от 1 до 9
  и m от 1 до n+1, включая неполные блоки.
- Формат итоговой строки, исходные S, N, M (включая m>n), неотрицательные
  времена T1 и T2, отсутствие отрицательного нуля во времени.
- Нулевые невязки для текущего временного решения (1,0,1,0,...).
- Наличие исполняемого файла `task_2/a.out` после обычной сборки.
- Норма относительно независимого расчёта по обычной матрице при n от 1
  до 19 и m от 1 до n+2; нули, знаки, дроби, NaN, inf и переполнение суммы.
- Печать прямоугольных матриц и векторов, включая неполные блоки и r=0
  (при r=0 не выводятся даже пустые строки).

Проверки рассчитаны на первый этап из `mail.txt`, где вместо алгоритма
решения используется временный вектор (1,0,1,0,...). Нулевые и вырожденные
матрицы должны успешно инициализироваться.

Исторические имена `invalid_separator_2.txt`, `invalid_inf_2.txt` и
`invalid_overflow_2.txt` не означают обязательный отказ: текущий ввод через
fscanf допускает соседние числа `2-2` и бесконечность в чётном столбце,
которая не попадает в b. Для бесконечных матриц проверяется ввод/вывод
и отказ решателя из-за бесконечной нормы: решение не выводится,
Res1 и Res2 остаются равными -1, T2 равно 0.
Переполнение суммы b, NaN, недостающие/лишние числа, текст и отсутствие
файла должны приводить к ошибке до итогового отчёта.

Границы внешних проверок:

- Закрытые методы, внутренняя раскладка памяти, повторное освобождение
  памяти и сохранность массивов напрямую не проверяются.
- Норма матрицы не выводится основной программой; она проверяется отдельным
  C++-тестом, который также проверяет сохранность матрицы и границы буфера.
- Нельзя задать произвольный вектор x, поэтому ненулевые невязки
  и их нормировка этими тестами не покрыты.
- Отсутствие выделения памяти внутри `compute_residuals()` больше
  не проверяется перехватом вызовов.

Сравнение трёх вариантов вычисления нормы: `make -C task_2 benchmark`.
Методика и результаты находятся в `../tests/benchmark_norm.md`.
