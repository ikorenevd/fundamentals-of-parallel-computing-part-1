# Матрицы для тестов

Размер задаётся аргументом `n`, в самих TXT-файлах заголовков нет.

| Файл | n | Назначение |
| --- | --- | --- |
| `scalar_1.txt` | 1 | Минимальный размер |
| `identity_3.txt` | 3 | Единичная матрица |
| `dense_4.txt` | 4 | Несимметричная матрица; проверка порядка элементов |
| `mixed_3.txt` | 3 | Знаки, дробные числа, экспоненциальная запись |
| `singular_3.txt` | 3 | Вырожденная матрица с корректным форматом |
| `zero_3.txt` | 3 | Нулевая матрица с корректным форматом |
| `matrix with spaces_2.txt` | 2 | Пробелы в имени файла |
| `invalid_empty.txt` | 2 | Пустой файл |
| `invalid_short_3.txt` | 3 | Недостаточно чисел |
| `invalid_extra_2.txt` | 2 | Лишнее число |
| `invalid_text_2.txt` | 2 | Текст вместо числа |
| `invalid_suffix_2.txt` | 2 | Буквы после числа |
| `invalid_separator_2.txt` | 2 | Допустимая запись `2-2 2 1`: матрица `[[2, -2], [2, 1]]` |
| `invalid_nan_2.txt` | 2 | NaN |
| `invalid_inf_2.txt` | 2 | Inf; ошибка инициализации из-за бесконечной нормы |
| `invalid_overflow_2.txt` | 2 | Переполнение при чтении даёт inf; ошибка инициализации |
| `invalid_rhs_overflow_3.txt` | 3 | Числа допустимы, но сумма для b переполняется |

Запуск тестов из корня репозитория:

```bash
bash task_3/test.sh
```

Скрипт проверяет эти файлы, четыре формулы и дополнительные
детерминированно создаваемые матрицы. Один полный запуск добавляет строку
T1/T2 в `task_3/results_full_4000_m1_2000.csv`; для отказов и ошибок записывается -1.
Стандартный набор включает размер n=4000 для s=1..3; случаев n>4000 нет.
Сочетание n=4000,m=1 заменено на n=2000,m=1 для s=1..3.
Матрицы Гильберта (s=4) используются только при n<=15.
Ограничения времени выполнения нет.

Состав наборов quick/full, параметры запуска, формат результатов и
отображение описаны в [../README.md](../README.md).

В task_3 работает настоящий блочный решатель: нулевые и вырожденные
матрицы инициализируются, но решатель сообщает `Res1 = Res2 = -1`.
NaN, Inf, переполнение нормы/правой части, неверное количество чисел
и отсутствие файла отклоняются при инициализации. Запись `2-2` допускается
текущим вводом через fscanf и читается как два числа `2` и `-2`.
