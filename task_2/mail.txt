Высылаю описание оформления реализации задач первого задания по "Практикуму на ЭВМ".
Первый этап задачи - это реализация всех описанных требований, кроме самого решения.
В качестве решения можно взять вектор (1,0,1,0,...), а в качестве обратной матрицы
- единичную матрицу.

Правила сдачи заданий:

1. Архив формата zip с задачей должен быть прислан до 16:00 02.10.2026
2. Архив должен называться фамилия_инициалы.zip, где фамилия и инициалы написаны в латинской транслитерации, например, Ashurov_AA.zip
3. Письмо должно прийти ответом на это письмо в режиме "Ответить", а не "Ответить всем"
4. Если письмо пришло не вовремя (или не пришло совсем), архив имеет неверное имя или/и формат, или отправлен всем, то задачи считаются не сданными
5. Внутри архива должны содержаться исходные файлы для задачи (cpp, h, Makefile). Если файлов не хватает (например, нет Makefile), или есть лишние (например, exe, out), то задача считается не сданной
6. Файлы должны компилироваться без предупреждений и ошибок, иначе задача считается не сданной
Флаги компиляции:

g++ -O3 -mfpmath=sse -fstack-protector-all -g -W -Wall -Wextra -Wunused -Wcast-align -Werror -pedantic -pedantic-errors -Wfloat-equal -Wpointer-arith -Wformat-security -Wmissing-format-attribute -Wformat=1 -Wwrite-strings -Wcast-align -Wno-long-long -Woverloaded-virtual -Wnon-virtual-dtor -Wcast-qual -Wno-suggest-attribute=format имя_файла.cpp

7. В результате запуска команды make должен получиться исполняемый файл с именем a.out, соответствующий выданной задаче
8. При использовании чужого кода задача считается не сданной
9. Исполняемый файл, получающийся в результате компиляции исходных файлов, должен пройти все тесты. Тогда задача считается сданной
