# Матрицы для тестов

Размер задаётся аргументом `n`, в самих TXT-файлах заголовков нет.

| Файл | n | Назначение |
| --- | --- | --- |
| `scalar_1.txt` | 1 | Минимальный размер |
| `identity_3.txt` | 3 | Единичная матрица |
| `dense_4.txt` | 4 | Несимметричная матрица; проверка порядка элементов |
| `mixed_3.txt` | 3 | Знаки, дробные числа, экспоненциальная запись |
| `singular_3.txt` | 3 | Вырожденная матрица с корректным форматом |
| `zero_3.txt` | 3 | Нулевая матрица с корректным форматом |
| `matrix with spaces_2.txt` | 2 | Пробелы в имени файла |
| `invalid_empty.txt` | 2 | Пустой файл |
| `invalid_short_3.txt` | 3 | Недостаточно чисел |
| `invalid_extra_2.txt` | 2 | Лишнее число |
| `invalid_text_2.txt` | 2 | Текст вместо числа |
| `invalid_suffix_2.txt` | 2 | Буквы после числа |
| `invalid_separator_2.txt` | 2 | Допустимая запись `2-2 2 1`: матрица `[[2, -2], [2, 1]]` |
| `invalid_nan_2.txt` | 2 | NaN |
| `invalid_inf_2.txt` | 2 | Допустимое значение inf (старое имя файла) |
| `invalid_overflow_2.txt` | 2 | Число вне диапазона double |
| `invalid_rhs_overflow_3.txt` | 3 | Числа допустимы, но сумма для b переполняется |

Запуск всех файлов из корня проекта: `bash task_2/test.sh`.
Скрипт сам собирает программу и работает из любого
каталога при указании пути к нему.

Скрипт находит все `*.txt`, берёт размер из суффикса `_N.txt`
(`invalid_empty.txt` проверяется при `n=2`) и перебирает `m` от 1 до `n+1`.
Если `m > n`, скрипт передаёт исходное значение `m` и проверяет, что программа
сама заменяет его на `n`: в итоговом отчёте должно быть `M = n`.
Для корректных файлов проверяются код возврата 0, напечатанные матрица и
правая часть, а также параметры итогового отчёта. Файлы `invalid_*`
должны завершаться с кодом 1 и сообщением об ошибке до итогового отчёта.
Исключение — `invalid_inf_2.txt`: значение `inf` допустимо, поэтому файл
проверяется как корректный ввод, включая печать бесконечности в матрице.
Также допустим `invalid_separator_2.txt`: знак следующего числа может идти
сразу после предыдущего числа, без пробела, как при чтении через `fscanf`.
Если вычисление невозможно, итоговый отчёт с `Res1 = -1` и `Res2 = -1`
считается нормальным результатом при коде возврата 0 или 1. Допускается
сопутствующая диагностика. Для файлов с переполнением допустим как такой
отчёт, так и отказ при инициализации. Ошибки формата и `nan` по-прежнему
должны отклоняться до итогового отчёта; невязки `-1 -1` их не оправдывают.
Любой провал даёт ненулевой код возврата скрипта; остальные тесты продолжаются.
Выводятся только проваленные тесты и их диагностика (либо ошибка сборки).
Если все тесты прошли, скрипт завершается без вывода.

Решатель и вычисление невязок пока не реализованы, поэтому проверяется
только загрузка и инициализация. Нулевые и вырожденные матрицы имеют
корректный формат и на этом этапе должны успешно загружаться.
